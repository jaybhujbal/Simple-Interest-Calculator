# Simple Interest Calculator Project

This project is a simple interest calculator implemented using a Bash script.

## About the Project

The Simple Interest Calculator calculates the simple interest earned on a principal amount over a specified period of time at a given interest rate.

The formula used is:

Simple Interest = (Principal × Rate × Time) / 100

Where:

- **Principal** = The initial amount of money
- **Rate** = The annual interest rate in percentage
- **Time** = The investment period in years

## How to Use

Run the `simple-interest.sh` script and enter the following values when prompted:

1. Principal amount
2. Rate of interest
3. Time period

The script will calculate and display the simple interest.

## Example

If:

- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100
