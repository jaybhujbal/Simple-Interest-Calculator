# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions are welcome. We appreciate your help in improving this project.

## Contributions

You are welcome to contribute improvements, new features, and useful ideas to the project. Please make sure your contributions are relevant to the project and follow the existing coding style.

## Bug Reports

If you find a bug, please report it by creating an issue. Include a clear description of the problem, steps to reproduce it, and any relevant error messages.

## Bug Fixes

Bug fixes are welcome. Before submitting a fix, please make sure you understand the problem and test your changes to ensure that the bug has been resolved.

## Documentation Improvements

Improvements to the documentation are encouraged. You can help by correcting errors, improving explanations, or adding useful information.

## Enhancements

Suggestions and contributions that improve the functionality, usability, or performance of the project are welcome.

## Ideas

New ideas and suggestions for improving the Simple Interest Calculator are encouraged. Please open an issue to discuss your idea before making major changes.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes.
6. Push your branch to GitHub.
7. Create a pull request.

Thank you for contributing!
